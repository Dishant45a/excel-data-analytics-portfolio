# Excel Data Analytics Portfolio

A collection of Excel projects demonstrating practical skills in **data analysis, business reporting, dashboards, data modeling, lookup functions, PivotTables, PivotCharts, Slicers, Scenario Manager, and Solver**.

## Projects

### 1. Sales Performance Dashboard

**File:** `Excel - Sales Performance Dashboard.xlsx`

An interactive sales analysis project built around a sales dataset with **9,800+ records**.

**Workbook includes:**
- Sales Data
- Sales Trend
- Sales by Region
- Product Share
- Sales by Segmentation
- Sales by State
- Interactive Dashboard

**Skills demonstrated:**
- Data analysis
- Sales trend analysis
- Regional and state-level analysis
- Product performance analysis
- Customer segmentation
- Dashboard creation
- Data visualization

---

### 2. Pivot Tables, Pivot Charts & Slicers

**File:** `Excel - Pivot Tables, Pivot Chart, Slicers.xlsx`

A reporting and analysis project using shipping data and interactive Excel reporting tools.

**Workbook includes:**
- Shipping Data
- Individual analysis sheets
- Main PivotTables
- Pivot-based reporting

**Skills demonstrated:**
- PivotTables
- PivotCharts
- Slicers
- Data summarization
- Interactive reporting
- Business data analysis

---

### 3. LOOKUP, INDEX, MATCH & SUMIFS

**File:** `Excel - LOOKUP, INDEX, MATCH, SUMIFS.xlsx`

A customer quotation and pricing model using an international price list and discount matrix.

**Workbook includes:**
- Customer Quote
- International Price List
- Discount Matrix

**Skills demonstrated:**
- LOOKUP functions
- INDEX
- MATCH
- SUMIFS
- Dynamic pricing/quotation logic
- Working with reference tables
- Business calculations

### 4. Scenario Manager & Solver — Data Modeling

## Purpose

These projects were created to develop and demonstrate practical Excel skills used in **data analytics, business analysis, reporting, and decision-making**.

The collection progresses from Excel formulas and reference-based calculations to interactive reporting, dashboards, scenario analysis, and optimization.
